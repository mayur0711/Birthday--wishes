## 🌟 Highlights & Features

- 💌 **Multi-Step Romantic Journey:**
  - **Step 1: The Invitation** — A glowing glassmorphic envelope card inviting the celebrant to open their surprise.
  - **Step 2: Birthday Cake & Love Cards** — An interactive cake section with a candle-blowing celebration, realistic confetti burst, and 4 flip cards revealing reasons why she is cherished.
  - **Step 3: Heartfelt Love Letter** — A heartfelt, personal letter styled with timeless typography, playful humor, and a signature sign-off.
- 🌸 **Canvas Particle Engine:** Continuous background animation with floating hearts, rose petals, and glittering sparkles using HTML5 Canvas.
- 🎶 **Pure Web Audio API Music:** Built-in synthesizer that plays gentle background melodies and chime sound effects without needing external audio files.
- 🎴 **3D Interactive Flip Cards:** Tap or click cards to flip them and uncover sweet memories and loving compliments.
- 🎉 **Confetti & Floating Hearts:** Particle explosions triggered when blowing out candles and pressing the *"Send Hearts & Kisses"* button.
- 📱 **Mobile & Desktop Responsive:** Fully responsive glassmorphism layout that looks stunning on phones, tablets, and wide screens.

## 🚀 Quick Start

No installation or node setup required! This project runs entirely on vanilla web technologies.

### Option 1: Run Locally
1. **Clone the repository:**
   ```bash
   git clone https://github.com/mayur0711/Birthday--wishes.git
   ```
2. **Open the project:**
   Simply double-click [`index.html`](index.html) to open it in any modern browser (Chrome, Edge, Safari, Firefox).
   
   *Or use VS Code Live Server:*
   Right-click [`index.html`](index.html) and select **Open with Live Server**.

### Option 2: Host for Free with GitHub Pages
1. Go to your repository settings on GitHub: **Settings** > **Pages**.
2. Under **Branch**, select `main` and root folder `/ (root)`.
3. Click **Save**.
4. In a few seconds, GitHub will provide a live link you can send directly to your loved one! 🎁

## 🎨 How to Customize for Your Loved One

Want to adapt this website for your partner, friend, or family member? You can easily customize it in minutes:

1. **Change the Names & Letter Text:**
   - Open [`index.html`](index.html).
   - Edit the salutation in `<h2 class="letter-salutation">` (e.g., change *"To My Dearest Wife"* to your loved one's name).
   - Update the paragraphs inside `<div class="letter-content">` with your own personal story, inside jokes, and wishes.
   - Update the signature in `<h3 class="signature-name">`.

2. **Customize the 4 Flip Cards:**
   - In [`index.html`](index.html), search for `.cards-grid`.
   - Update the front title (`<h3>Your Radiant Smile</h3>`) and the back message (`"Your smile lights up..."`) to match your favorite memories together.

3. **Change Images:**
   - Place your photos inside the `assets/` folder and update the `src` attribute in [`index.html`](index.html).
